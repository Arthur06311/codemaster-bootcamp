📋 Para ativar rastreamento de visitas, crie a tabela no Supabase:

CREATE TABLE page_views (
  id bigserial PRIMARY KEY,
  ts timestamptz DEFAULT now(),
  ref text
);
ALTER TABLE page_views ENABLE ROW LEVEL SECURITY;
CREATE POLICY "allow insert" ON page_views FOR INSERT WITH CHECK (true);
CREATE POLICY "allow read" ON page_views FOR SELECT USING (true);

Acesse supabase.com → SQL Editor e cole o código acima.
